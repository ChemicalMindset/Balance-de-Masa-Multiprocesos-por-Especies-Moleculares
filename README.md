# Balance-de-Masa-Multiprocesos-por-Especies-Moleculares
Simulación multiprocesos para balance de masa por especies moleculares. Permite el calculo de cada componente químico para dos variables: corriente másica de alimentación del reactor o corriente másica de productos deseados.

---

El proyecto se encuentra incompleto. Se encuentra desarrollada la primera reacción de predicción de corriente de producto a partir de la corriente de alimentación. Queda pendiente:

- Un script que permita predecir la corriente de reactivos para una corriente de productos indicada por el usuario.
- Ampliar el catalogo de posibles reacciones.
